# Django Student Portal

A simple student management web app built with Django. It supports full CRUD operations and a login system.

## Features
- Create, view, update and delete students
- Login and logout using Django's built-in authentication
- Admin panel for managing data
- Bootstrap styled student list

## Tech Stack
- Python
- Django
- SQLite
- HTML and Bootstrap

## How to Run
1. Clone the repository
2. Install Django: pip install django
3. Run migrations: python manage.py migrate
4. Create an admin user: python manage.py createsuperuser
5. Start the server: python manage.py runserver
6. Open http://127.0.0.1:8000 in your browser
